daisy2telmi

Drop a DAISY 2.02 audiobook pack, get a Telmi story folder. Nothing is uploaded: the conversion runs in this tab.

What you get

        

          One Telmi chapter per top-level DAISY chapter, plus a silent menu card before each one so
          the story is navigable with the Telmi buttons. The pack's spoken title becomes
          title.mp3.
        

        

          The zip is named the way Telmi Sync names stories,
          <category>_<age>_<title>_<uuid>, and imports straight
          from the Import → zip menu.
        

      


      

        
Before you convert

        
    
          
  • 
            Audio is kept at the source rate instead of being re-encoded. Telmi's player resamples to
            44100 Hz itself, so it plays, but the quality stays where the DAISY pack left it.
          
    • 
          
  • 
            Clips are taken as whole files. A pack that trims inside a file will keep the whole file;
            use the command line tool for exact clip ranges.
          
    • 
          
  • Only audio books are handled. Synchronised text and TTS are not.
    • 
          
  • Scene images are generated placeholders showing the chapter number.
    • 
        

        

          For exact re-encoding and clip trimming, use the
          command line converter, which ships
          for Windows, Debian and macOS.
        

      


      

        
The desktop app does more

        

          A browser tab cannot run a speech synthesiser and write its output into the pack, so the
          chapter cards here stay silent. The desktop converter can speak them: each card says the
          chapter number, and can ask whether to continue, in English, French, Chinese, Arabic,
          Turkish, German, Italian, Spanish, Portuguese or Dutch. It also re-encodes audio to
          Telmi's exact spec, trims clips, and its window can be shown in those same languages.
        

        

          Get it from the
          releases page for Windows,
          Debian, Ubuntu, macOS or as an AppImage.
